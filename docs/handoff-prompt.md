## How to Spin Up Agents

```
# 1. Create a team
TeamCreate: team_name="next-phase", description="..."

# 2. Create tasks
TaskCreate: subject="...", description="...", activeForm="..."

# 3. Spawn agents (ALWAYS use isolation: "worktree")
Task tool with:
  name: "agent-name"
  subagent_type: "general-purpose"
  team_name: "next-phase"
  isolation: "worktree"
  run_in_background: true
  prompt: '...'

# 4. When agents finish, shut them down
SendMessage: type="shutdown_request", recipient="agent-name"

# 5. When all done, clean up
TeamDelete
```

Always tell agents:
- Work on branch `ducklake-features/integration`
- Use `isolation: "worktree"` so each gets its own copy
